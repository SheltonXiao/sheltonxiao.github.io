# Tong Xiao's Academic Portfolio

This repository contains the source code for my personal academic homepage, which is hosted at [sheltonxiao.github.io](https://sheltonxiao.github.io/).

## 🌟 Key Features
- **Project Gallery**: A professional showcase of research, engineering, and competition projects.
- **Automated Visualizations**: Features a specialized Python pipeline (`generate_visuals.py`) to generate publication-quality word clouds and geographic participant maps for project galleries.
- **Categorization System**: Projects are organized using a custom tagging system (Research, Engineering, Comprehensive).
- **Responsive Design**: Mobile-friendly layout with optimized typography and sidebar navigation.

## 🛠️ Maintenance & Development

For local debugging with Jekyll:
```bash
bash run_server.sh
```
